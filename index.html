La web trabaja.
Vosotros cortáis.

Hoy la cita se pide por teléfono, con las manos ocupadas. Con esta web cada paso sale solo, desde la reserva hasta la siguiente visita.

Al reservar

Confirmación al instante por WhatsApp con día, hora y barbero. El hueco queda bloqueado.

24 horas antes

Recordatorio con un enlace para confirmar, cambiar la hora o cancelar sin llamar.

Si alguien cancela

La hora vuelve a aparecer en la web y se avisa a quien estaba en lista de espera.

Después del corte

Mensaje de gracias con el enlace para dejar una reseña en Google.

A las [X] semanas

Aviso de que ya toca repasar, con un botón para reservar otra vez en un toque.
